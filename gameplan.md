                Cyber security game:
            Mission/Loop:
            Start Game -> start menu -> select night (1-7) -> if night one then display instructions on how to play, open with cutseen. if other night no instructions needed unless a new event is introduced.
            
            Lore:

            Gameplay: 
        time system: the time system is meant to be used as a kinda event causer, for example when it turns 5pm in game there will be a random event that happens like a popup, virus attack, suspicous message, ect. each hour in game is 5 min in real life. each day is 8 hours and its a 7 week game. events can stack if not done in time, if you have to many events happening you will lose. the objective is to survive all 7 days, after every day the difficulty will get harder. you do not have to do all 7 days straight, you can do day one, then wait a while then do day 2.
